# ARFAD International Industrial Co. — Website

This repository has two parts:

- **`frontend/`** — the current public ARFAD website: a static site generated by
  `build.py` (Python) into plain HTML/CSS pages. This is what's currently live
  (published as a Claude Artifact). Run `python3 build.py` to regenerate the
  HTML from the template source after editing it.
- **`backend/`** — `arfad-admin`, a separate Next.js 14 admin/CMS app (NextAuth +
  Drizzle/SQLite) for editing site content (services, projects, settings, media)
  through a web UI, with its own database. See `backend/README.md` for setup,
  deployment, and how to wire it up to replace the static frontend's hardcoded
  content over time.

The two are not yet connected — `frontend/` is still generated from hardcoded
Python data, and `backend/` is a standalone app with its own public pages. See
`backend/README.md`'s "Extending it" section for how to connect them.
